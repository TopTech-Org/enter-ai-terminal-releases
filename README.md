# Enter AI Terminal — ไฟล์อัปเดต (Mac)

repo นี้เก็บแค่ไฟล์ปล่อยของแอป **Enter AI Terminal** (ไม่มีโค้ด)

- แอปเช็ค `releases/latest/download/latest.json` เพื่ออัปเดตตัวเอง (เซ็นด้วยกุญแจ Tauri updater)
- ติดตั้งครั้งแรก: ดาวน์โหลด `Enter-AI-Terminal-mac.zip` จาก Release ล่าสุด → แตกไฟล์ → ลาก `Enter AI Terminal.app` ไปไว้ใน Applications
